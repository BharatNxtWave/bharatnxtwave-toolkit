BharatNXT Wave — BDE Redesign V1.2

Changes
- Removes duplicate page-level search boxes from Business Toolkit and Service Library.
- Makes the existing top-bar search the single smart search across the BDE workspace.
- Adds ranked live service recommendations/typeahead to the top-bar search.
- Recommendation click opens Quick View without leaving the current screen.
- Keyboard support: Ctrl+K, Arrow Up/Down, Enter, Escape.
- Service Library full search now uses the same sector-aware matching as Business Toolkit.
- Adds calm feedback for Save, Quick View, scheme links, filters and Client Finder submission.
- Adds loading skeletons and clearer failure states.
- No database migration and no data changes.
